# 🚀 Quick Start: AI Assistant

## Set Up Your OpenAI API Key (One Time)

### Step 1: Get Your API Key
Visit: https://platform.openai.com/api-keys

### Step 2: Add to Your Shell
```bash
# Add this line to your ~/.bashrc
echo 'export OPENAI_API_KEY="sk-your-actual-api-key-here"' >> ~/.bashrc

# Reload your shell
source ~/.bashrc
```

### Step 3: Start the Simulation
```bash
source ./aix_simulation.sh
```

You should see:
```
🤖 AI Assistant: ENABLED - Type 'ask <question>' for help
```

## Try It Now!

```bash
# Ask in plain English
ask how do I check disk space?
ask show me all running processes
ask what's the AIX version command?
ask how to monitor CPU performance?
```

| Command | What It Does |
